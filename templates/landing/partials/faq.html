Perguntas frequentes

Preciso conectar meu banco? +
Não. O GranaGo não exige integração bancária. Você registra o que quiser, no seu ritmo — sem sincronização obrigatória.
É difícil de manter no dia a dia? +
Foi feito para ser simples o suficiente para funcionar até nos meses mais corridos. Com o uso, a categorização inteligente reduz o trabalho manual — não aumenta.
Já tentei outros apps e desisti. Por que seria diferente? +
O GranaGo foi feito para quem desistiu dos outros apps. Sem configuração longa, sem tutorial de 20 minutos — só uma resposta clara toda vez que você olhar: para onde foi o meu dinheiro?
Preciso entender de finanças? +
Não. Você não precisa ser especialista financeiro — só precisa enxergar. O GranaGo torna tudo visível; você só precisa olhar.
Como funciona a garantia de 7 dias? +
Se não funcionar para você, devolvemos tudo. Sem perguntas, sem burocracia.
O preço vai aumentar? +
O preço de lançamento é por tempo limitado. Quando o período de lançamento encerrar, o valor será reajustado.
