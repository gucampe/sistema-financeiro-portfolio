## O que a UI no lugar já cobre

- **Resultado do período** vs **Saldo das contas**: nomes unificados + `ⓘ` no dashboard.
- **Cartão ≠ conta**: empty state de Cartões, `ⓘ` em Fatura atual, hint de transferência.
- **Por que cadastrar conta**: empty states da Visão geral e de Contas.

## Decisões (seguir para Fases 2–5)

1. **Os 3 artigos MVP nascem na Fase 4:** `mapa`, `adicionar-dados`, `cartao`.
   O mapa mental, o dual path (lançar / importar extrato) e o modelo do crédito ainda não cabem só no `ⓘ`.
2. **“Como corrigir uma categoria”:** não entra no catálogo. Continua só âncora se uma dica contextual precisar.
3. **Sidebar Relatórios:** não renomear. As abas internas já dizem “Visão geral”.
