Pasta para ideias de produto **já exploradas no código ou no desenho**, mas **retiradas ou não lançadas**. O objetivo é não perder o raciocínio técnico e os motivos (produto, privacidade, custo) se alguém quiser retomar no futuro.

Anotar uma ideia aqui **não é tratamento de dado pessoal** e **não fere a LGPD**. São notas internas de engenharia/produto, sem base de usuários e sem coleta em produção.
